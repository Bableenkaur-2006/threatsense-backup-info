PERSONAL BACKUP UTILITY

ThreatSense Backup Uploader

A personal utility operated by Bableen Kaur to transfer encrypted ThreatSense recovery archives from her computer to her own Google Drive using rclone.

The Google connection uses the drive.file permission for files and folders created or opened with this application. The utility is intended for the owner's personal use.

This website provides application information. It does not upload backups, request Google credentials, or provide access to the ThreatSense application.
